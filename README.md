# Sales Discount Analysis

Analysis of 15,000 Indian retail orders to find out whether discounts pay off.

## Questions
- Which regions lead in sales and profit?
- How do discounts affect profit per order?

## Key findings
- South leads in sales and profit because it has the most orders.
- Average profit per order falls from ₹2004 (no discount) to ₹1493 (30% discount).
- Order value stays flat, so deeper discounts don't bring larger orders.
- Profit margin on net sales stays about 38%, but profit per order still drops.

## Tools
Python, pandas, matplotlib, Jupyter Notebook (VS Code)
